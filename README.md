# 🦊 critter-heads

Animated cartoon animals for React and the web: ten critters, each with 12 expressions they act out their own way, and an idle life of their own. Pure SVG, zero runtime dependencies, and frame-exact, so every frame renders the same every time. Use them for AI agents, apps, explainer videos, streams, games or stickers.

Cast: 🦊 Kit (fox) · 🦉 Hoot (owl) · 🐱 Miso (cat) · 🦝 Bandit (raccoon) · 🐼 Bao (panda) · 🐕 Kona (shiba) · 🐰 Pippin (bunny) · 🐻 Barnaby (bear) · 🐸 Moss (frog) · 🦦 Ollie (otter).

**Try them in the Studio:** https://critters-studio.vercel.app

## 📦 Install

```bash
npm i critter-heads
```

```jsx
import { CritterHead } from "critter-heads";

<CritterHead character="frog" expression="happy" />
```

Not using React? `critter-heads/vanilla` gives you `createCritter()` and a `<critter-head>` element. Full API: [packages/critter-heads/README.md](packages/critter-heads/README.md).
